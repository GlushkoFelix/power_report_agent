【一、全局外壳与入口】
----------------------------------------------------------------------

1. 登录 / 注册页  （路由 /login · pages/Login/index.tsx）
   版式：左品牌区（<1024px 隐藏）+ 右表单卡；页面自身为滚动容器。
   · 模式切换：登录 / 注册
   · 登录表单：用户名、密码 → 按钮「登录」
   · 注册表单：用户名、密码、确认密码、显示名（可选） → 按钮「注册」
     （注册成功即自动签发 JWT 并登录）
   · 错误处理：表单内显示错误码 + 修复提示（hint）
   · 账号锁定：连续 5 次失败 → 锁 5 分钟，页面显示倒计时
   · 已登录访问本页 → 自动跳走（带 next 回跳目标）

2. 主外壳  （layouts/MainLayout.tsx）
   · 进入应用时自动打开「最近一个会话」（仅首次，避免反复抢焦点）
   · 未登录访问受保护路由 → 重定向登录页并携带 next

3. 顶栏  （layouts/TopBar.tsx · 全局常驻）
   · 左侧品牌区：点击回到对话工作台（/）
   · 主导航 4 项：对话工作台(/)、报表管理(/reports)、评测中心(/eval)、个人中心(/profile)
   · 「当前报表」选择器（Select，宽 200px）
     - 选项格式：报表编号（类型中文名），如 r_minute（分钟表）
     - 切换后：会话活跃报表变更 + 条件（slot）清空 + 提示「条件已重置」
     - 尚无会话时：仅记住选择，新建会话时生效
   · 主题切换：开关按钮（亮色 ↔ 暗色，Tooltip 提示目标主题）
   · 账号下拉菜单：个人中心 / 退出登录（退出不带 next，与 401 失效语义区分）

4. 页头  （layouts/PageHeader.tsx）
   · 标题 + 副标题 + 可选的说明 Tooltip；被四个业务页面复用

【二、对话工作台】（路由 / · pages/Workbench/）
三栏版式：左 240px 会话列表 ｜ 中 对话流 ｜ 右 408px 图表与表格（窄屏变抽屉）
----------------------------------------------------------------------

2.1 会话列表  （ConversationList.tsx）
   · 「展开 / 收起会话列表」按钮（面板折叠图标）
   · 「新建会话」按钮（顶部 + 空态各一处；重复点击有防抖）
   · 会话条目（点击切换会话）——每条显示：标题、最后时间、消息数、
     以及**该会话自己的活跃报表**（如 · r_daily）
   · 行内操作（hover 出现）：重命名、置顶 / 取消置顶（每人≤5 条）、删除会话（二次确认）
   · 底部快捷入口按钮：按配置跳转到其它页面

2.2 对话流  （MessageStream.tsx）
   · 用户气泡：问题原文 + 当时使用的报表编号
   · 助手气泡：阶段时间轴 → SQL/代码块 → 数据表 → 图表 → 文字解读（打字机效果）
   · 助手气泡动作按钮：
     - 「复用条件」：把本轮生效的条件固化为当前口径（Tooltip 说明）
     - 「重试」：用同一问题重跑
     - 「复制 SQL / 代码」
     - 「导出」（导出本轮结果）
   · 澄清卡：显示缺失槽位 + 候选指标，点选即回填并续跑
   · 拒绝卡：超范围提示 + 建议问题按钮（点击即提问）
   · 错误卡：错误码 + 修复提示

2.3 输入区  （Composer.tsx）
   · 多行输入框（占位文案示例：「2020 年 7 月的总用电量是多少」）
   · 「发送」按钮（主色；提交后进入流式）
   · 「停止」按钮（流式中出现，红色，中断本轮）
   · 示例问题快捷按钮（Tooltip 展示完整问题，点击直接提问）

2.4 条件芯片栏  （SlotBar.tsx）
   · 芯片（chips）：时间范围 / 指标 / 维度 / 粒度 / 对比 / 过滤，
     每个芯片显示当前值，长值 Tooltip 展开
   · 点击芯片 → 编辑弹层：
     - 时间范围：日期区间选择（DatePicker 双选）
     - 指标：选择或输入（可搜索、可自定义）
     - 维度：下拉选择
     - 粒度：下拉选择（日 / 月 / 年等）
     - 对比：下拉选择
     - 过滤：多选（Checkbox 组，如只看工作日）
   · 「按新条件重算」按钮（主色 + 刷新图标；直接重跑上一次问题）
   · 「取消本次修改」按钮（丢弃未提交的条件改动）
   · 生成中禁用编辑（防并发改条件）

2.5 结果面板  （ResultPanel.tsx · 桌面右栏 408px / 窄屏抽屉全宽）
   · 图表类型切换（分段控件：柱状 / 折线 / 饼图等）
   · 「导出 PNG」按钮（2 倍图、亮色底；无结果时禁用并提示"尚未生成结果"）
   · 聚合粒度选择（Select，「原粒度」为默认项）
   · 「查看字段字典」链接（打开 SchemaDrawer）
   · 空态提示（无结果时的引导文案）

2.6 结果表格  （ResultTable.tsx）
   · 列头 Tooltip：比率列提示「不可相加，跨周期需分子分母分别求和」；普通列显示类型
   · 异常数据点标记 + Tooltip（异常原因）
   · 不完整周期标记 + Tooltip（跨周期对比需谨慎）
   · 行 hover 与图表联动高亮（.zd-row-active）
   · 「按月聚合」按钮（把当前结果按月份归并）

2.7 代码块 / 阶段时间轴 / 执行信息
   · CodeBlock.tsx：「展开 / 折叠」代码、「复制」按钮、
     「查看字段字典」链接、守卫通过标记（Tooltip：已过只读白名单 / AST 预检）
   · StageTimeline.tsx：各阶段进度（解析问题 → 生成 SQL → 执行 → 解读）；
     有自愈重试时显示「已带错误信息重写 N 次」
   · ExecInfo.tsx：路由、耗时、token、模型、重试次数等执行信息；
     模型实现方式 Tooltip（未配置 Key 时提示走离线脚本模型）；底部免责声明

2.8 字段字典抽屉  （SchemaDrawer.tsx）
   · 标题「字段字典 · 报表编号」；按分组折叠展示
   · 每列显示：列名、类型、单位、口径标注、示例值
   · 底部口径提示（比率列 agg: none 等）

2.9 页面级功能  （Workbench/index.tsx）
   · 无可用报表时的引导卡：「去上传报表」（跳报表管理）
   · 窄屏「查看结果」按钮 → 打开结果抽屉（标题「结果：图表与数据表格」）
   · 空会话欢迎区：说明 + 当前报表信息（文件名 / 编号 / 数据范围 / 行数）

【三、报表管理】（路由 /reports · pages/Reports/）
版式：① 上传区（可折叠）② 报表列表 ③ 预览抽屉 ④ 质量报告抽屉 ⑤ 字段字典抽屉
----------------------------------------------------------------------

3.1 页面级  （Reports/index.tsx）
   · 「刷新」按钮（重新拉取报表列表）
   · 「上传报表」按钮（展开 / 收起上传向导）
   · 列表列：报表编号、文件名、类型（分钟表/小时表/日报/月报/结构表/上传）、
     行数、时间范围、状态（pending/parsing/ready/failed）、是否当前报表、操作
   · 列表行操作按钮：
     - 「预览」→ 打开预览抽屉
     - 「质量报告」→ 打开质量抽屉
     - 「字段字典」→ 打开字段字典抽屉
     - 「设为当前报表」→ 切换会话活跃报表（已是当前时禁用并提示「已是当前报表」）
     - 「删除」→ 二次确认（Popconfirm）；系统预置报表按钮置灰并提示
       「系统预置报表不可删除（全用户共享数据源）」
   · 异常提示：元数据存在但物理表缺失时给出图标 + Tooltip 说明
   · 当前报表高亮：会话内取会话活跃报表；无会话时回落系统默认活跃报表

3.2 上传向导  （UploadWizard.tsx · 两步）
   · 步骤条：① 上传与解析 → ② 确认入库
   · 第一步：选择文件（仅 .csv/.txt）、上传进度、解析中状态、解析结果预览表
   · 第二步：确认入库（按钮「确认入库」）／放弃（按钮「取消」）
   · 完成后（按钮三个）：
     - 「设为当前报表」→ 激活该表并可直接开始提问
     - 「查看字段字典」
     - 「继续上传」（重置向导）
   · 校验：扩展名、大小（后端上限 200MB）、sha256 重复文件提示

3.3 预览抽屉  （PreviewDrawer.tsx）
   · 分页查看已入库数据的前若干行；列名与类型对齐字段字典

3.4 质量报告  （QualityPanel.tsx）
   · 键值卡片 + 逐项 Tooltip：整行缺失、重复时间戳、时间轴缺口、
     有效分钟覆盖率、异常日、以及各口径统计项

3.5 字段字典  （复用 Workbench/SchemaDrawer.tsx）
   · 同 2.8：分组折叠的字段清单（列名/类型/单位/口径/示例）

【四、评测中心】（路由 /eval · pages/Eval/）
版式：① 发起评测面板 ② 批次列表 ③ 批次详情（指标 + 逐题明细）
----------------------------------------------------------------------

4.1 页面级  （Eval/index.tsx）
   · 「发起评测」按钮 → 打开发起弹窗
   · 批次详情弹窗：指标面板 + 逐题明细表
   · 弹窗内导出：「导出 PDF」「导出 Markdown」（下载报告文件）
   · 「关闭」按钮
   · 批次进行中状态展示（排队 / 运行中 / 完成）

4.2 发起面板  （StartPanel.tsx）
   · 执行模式（分段控件）：
     - 「真实模型（real）」：逐题走完整 Agent 链路、消耗 API 额度；无 Key 返回 400
     - 「自检回放（selfcheck）」：按题库 gold 回放 + 标准解读，不消耗 token，
       用于验证「题库 → 链路 → 判分 → 指标 → 报告」全通
   · 题量（分段控件）：全量（120 题） / 抽样
     - 抽样时用数字输入框指定题数（1 ~ 题库总量）
     - 说明：题库含口径陷阱题（R1/R3/R6/R7），抽样按题库顺序取前 N 题
   · 「生成文字解读」开关：开=计入结论命中率；关=跳过解读（更快）
   · 批次名称输入框（可选，如「prompt-v3.0 首跑」，最长 60 字）
   · 「发起评测」按钮（主色，提交中禁用）——异步执行，返回批次编号

4.3 批次列表  （RunsList.tsx）
   · 每条批次显示：批次编号、名称、模型、提示词版本、题量、
     执行正确率、结论命中率、P95 延迟、状态、时间
   · 行操作按钮：
     - 「查看详情」→ 打开批次详情
     - 「下载 Markdown 原文」→ 便于二次处理与归档（Tooltip 说明）
   · 仅显示本人批次（跨用户不可见）

4.4 指标面板  （MetricsPanel.tsx）
   · 核心指标卡：执行正确率、结论命中率、平均耗时、P95（Tooltip 解释 P95 含义）
   · 分题型 / 分难度正确率分布
   · 错题归因分类统计（口径理解错误 / 澄清未执行 / SQL 语法与函数 /
     slot 继承错误 / 执行失败未重试成功 / 结果口径偏差）
   · 自检模式的显著提示：「自检回放（不代表模型能力）」

4.5 逐题明细  （RunQuestionsTable.tsx）
   · 视图切换（分段控件）：全部 / 仅错题 等
   · 每行：题号、问题、题型、难度、是否正确（分档标签）、
     陷阱题标记（Tooltip 显示 R1/R3/R6/R7）、生成 SQL / 代码（Tooltip 展开）、
     差异类型与说明、耗时
   · 错题高亮，便于逐题复盘

【五、个人中心】（路由 /profile · pages/Profile/）
版式：① 账号信息卡 ② 我的数据统计卡 ③ 我的分析记录（表格 + 时间筛选）
----------------------------------------------------------------------

5.1 账号信息卡
   · 展示：用户名、显示名、注册时间等
   · 「修改密码」按钮（Tooltip：需输入当前密码确认身份；
     改密后其它设备上的登录不会自动退出）
   · 「编辑资料」按钮 → 打开编辑资料弹窗

5.2 我的数据统计卡
   · 统计项：分析次数、会话数、我的报表数、评测批次数等
   · 「清空历史」按钮（红色，Tooltip：可选「只清分析记录（保留会话）」
     或「清空全部会话与对话历史」）
   · 「删除账号」按钮（红色，Tooltip：密码 + 用户名双确认；
     上传报表（含物理表）、会话、记录与评测批次一并删除）

5.3 我的分析记录
   · 搜索：关键词输入框（占位「搜索问题关键词」）+「搜索」按钮
   · 「刷新」按钮
   · 时间范围筛选（更新时间 / 创建时间，含当天）+「清除筛选」按钮
   · 记录行内容：问题、使用的报表、耗时、是否正确/状态、时间
   · 记录行操作按钮：
     - 「详情」→ 打开记录详情抽屉（SQL/代码、结果表、图表与解读）
     - 「重跑」→ 新建会话并按**该记录当时的报表**重新执行
     - 「删除」→ 二次确认（Popconfirm）

5.4 弹窗与抽屉
   · 修改密码弹窗：当前密码（用于确认身份）、新密码（≥8 位含字母与数字）、
     确认新密码
   · 编辑资料弹窗：显示名（留空则回退为用户名，可一键清除）、邮箱（可选）
   · 清空历史弹窗：两种范围二选一（只清分析记录 / 清空全部会话与对话历史）
   · 删除账号弹窗：输入用户名 + 密码双确认（危险操作按钮统一样式）
   · 记录详情抽屉：问题、生成 SQL/代码、结果表、图表、文字解读、
     重试次数（含「已换路」标记）、耗时与模型等

【六、跨页公共部件与全局机制】
----------------------------------------------------------------------

6.1 状态卡组  （Workbench/StateCards.tsx）
   · 澄清卡：显示缺失槽位 + 候选指标，点选即回填续跑
   · 拒绝卡：问题超出当前报表范围时的提示 + 建议问题按钮
   · 错误卡：错误码 + 修复建议
   · 空结果卡 / 安全拦截卡（命中守卫时提示已写入安全审计日志，
     Tooltip 说明审计内容：用户、时间、命中规则与原始内容）

6.2 文字解读  （Typewriter.tsx）
   · 解读逐字呈现（打字机效果），流式到达即开始显示

6.3 图表  （ResultChart.tsx · 封装 plotly.js-dist-min）
   · 按结果自动选图（或按用户选择）；峰平谷/用途使用语义色
   · 点击图表数据点 ↔ 表格行联动高亮
   · 支持导出 PNG（见 2.5）

6.4 全局请求与错误  （api/client.ts / api/errors.ts / utils/toast.ts）
   · 统一响应包络解析（code / message / data / request_id）
   · 401 统一拦截：跳登录并保留草稿（回跳 next）
   · 错误码 → 中文提示映射（含 hint 修复建议；错误提示带 request_id 便于排查）
   · SSE 客户端封装（api/sse.ts）：POST + 鉴权头、统一事件分发、
     AbortController 可中断、**不自动重连**（避免重复提问消耗额度）

6.5 主题与设计令牌  （theme/tokens.ts · stores/theme.ts）
   · 亮色 / 暗色双主题，切换即时生效并持久化
   · 语义色板：峰/平/谷、用途四类、异常、比率等；后端只返回语义标记，
     主题由前端渲染

6.6 格式化  （utils/format.ts）
   · 数值（千分位、精度按列口径）、单位（kWh/kW/%）、时间、
     相对时间（列表"最后活动"）

6.7 响应式（UIUX 10.1 / 10.2）
   · 桌面：工作台三栏（240 / flex / 408）
   · 窄屏：右栏结果变抽屉；左栏会话列表可折叠；登录页品牌区 <1024px 隐藏
   · 页面内容区最大宽度 1440px

【七、页面 ↔ 接口对照】（统一前缀 /api/v1，共 39 条端点）
----------------------------------------------------------------------

7.1 全局（顶栏 / 外壳）
   · GET  /system/health                     健康检查（免鉴权，用于探活显示）
   · POST /auth/logout                       退出登录
   · GET  /reports                           顶栏「当前报表」下拉框的数据源
   · PATCH /conversations/{code}             切换会话活跃报表（带 active_report_code）

7.2 登录页 /login
   · POST /auth/register                     注册（免鉴权，成功即登录）
   · POST /auth/login                        登录（免鉴权，5 次失败锁 5 分钟）

7.3 对话工作台 /
   · GET  /conversations                     会话列表
   · POST /conversations                     新建会话（可带 active_report_code）
   · GET  /conversations/{code}              会话详情（含 slot 与活跃报表）
   · PATCH /conversations/{code}             重命名 / 置顶 / 切换活跃报表
   · DELETE /conversations/{code}            删除会话
   · GET  /conversations/{code}/messages     消息历史（游标分页）
   · POST /analysis/chat                     提问（SSE 流式）
   · POST /analysis/clarify                  澄清回填后继续（SSE 流式）
   · GET  /reports/{code}/schema             字段字典抽屉
   · GET  /analysis/records/{code}           结果详情（导出/复制所需）
   · POST /charts/rerender                   图表重绘（不调模型）
   · GET  /analysis/records/{code}/chart.png 导出图表 PNG（接口已预留，当前 501）

   · GET  /reports                           列表；GET /reports/{code} 详情

【附：口径提醒】
----------------------------------------------------------------------
· 「当前报表（活跃报表）」是**会话级**设置：每个会话各记一个，切表会清空条件。
· 评测批次**不受当前报表影响**：按每题的 report_table 自动激活对应表。
· 重跑使用**记录当时的报表**，不受当前选择影响。
· 自检批次（selfcheck）仅验证链路自洽，**不代表模型能力**，界面已标注。
