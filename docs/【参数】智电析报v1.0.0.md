## 二、概要

通过学习本案例，可了解基于 LLM 的对话式数据分析（ChatBI / Text2SQL）系统的系统架构与技术实现，
掌握**报表解析与 Schema 描述、自然语言转 SQL / pandas 代码、受控沙箱执行、图表与文字解读生成、
多轮追问（条件继承与主动澄清）、以及自动评测与 bad case 迭代**的完整开发方法，
为后续相关课程学习及将来从事数据分析、大模型应用开发领域的工作奠定基础。

能源电力行业日常产生大量用电报表数据，园区能耗管理员、售电公司分析师与企业设备管理人员需要频繁
开展用电量统计、峰谷时段分析、异常用电识别等工作。传统分析流程依赖专业人员编写 SQL 或操作 Excel，
门槛高、周期长。本案例以 UCI 家庭用电分钟级数据集（近四年连续观测）为真实数据底座，构建
"**上传报表 — 对话提问 — 图表结论**"的一站式分析入口，让非技术岗位也能直接以自然语言获取数据结论。

**本案例的核心特色是采用 AI 共创开发模式**，即在产品研发过程中，借助大语言模型等 AI 工具，
辅助完成文档撰写、方案设计、代码开发与测试评测工作。开发过程按
**PRD → UI/UX → 架构与数据库 → 前端 → 后端 → 测试与评测** 六个阶段推进，
每个阶段以"**评审清单 + 决策记录**"驱动（可查阅 `AI共创过程文档/` 的历史版本），
让学习者专注于理解业务逻辑与技术原理，而非繁琐的编码细节。

## 四、目标

1. **数据源接入与 Schema 理解**：支持 CSV 报表上传与解析，自动识别字段名称、数据类型、时间范围
   与数值分布，生成表结构（Schema）描述供大模型理解；对缺失值与异常值给出清洗提示，支持多张报表
   切换分析。
2. **自然语言转 SQL 与分析编排**：实现自然语言到 SQLite 查询语句与 pandas 分析代码的转译，
   在受控沙箱中执行，支持总量统计、分时段聚合、同比环比、峰值识别等分析任务，并由大模型对执行结果
   生成文字解读、识别异常用电模式。
3. **可视化输出**：支持折线图、柱状图、饼图等图表自动生成与切换，图表与数据表格联动展示，
   支持图表图片导出。
4. **多轮追问管理**：支持带上下文记忆的连续追问（如"只看周末的""再按月汇总一次"），
   自动继承前序查询条件，对歧义问题主动澄清确认。
5. **评测模块**：构建不少于 100 条的测试问题集，覆盖统计、聚合、对比、异常分析等提问类型，
   评测执行正确率与分析结论准确性，针对 bad case 迭代 Schema 描述与提示词。
6. **用户管理**：实现用户注册、登录、会话与分析记录管理，保障用户上传数据安全。

**验收口径（任务书）**：Text2SQL 执行正确率 **≥85%**、平均响应时间 **≤8 秒**（简单问数口径）。
**实测结果如实登记在《智电析报_测试报告》**（含 120 题评测集的正确率、结论命中率、
延迟 P95 与未达标项的逐条说明）——本表只写目标，不替代报告中的实测数字。

## 五、流程

1. **数据准备与口径校验**：原始分钟级数据清洗 → 5 张报表（分钟 / 小时 / 日 / 月 / 用电结构）
   → 数据质量报告 → 口径校验锚点（三级总量、用途四项与时段三项闭合、未计量占比）。
2. **Schema 构建与注入**：逐列标注单位、口径、是否可聚合、两套拆分不可混加等约束，
   生成注入文本（前端数据字典与注入给模型的文本逐字一致）。
3. **对话与意图解析**：自然语言 → 结构化 slot（时间范围 / 粒度 / 指标 / 维度 / 过滤 / 对比 /
   意图 / 图表倾向），会话内增量继承，缺失关键项时发起**澄清**。
4. **代码生成与安全执行**：双工具路由（SQL / pandas）→ 生成前守卫
   （只读白名单、强制 LIMIT、混加检测）→ 沙箱执行（子进程隔离、超时 / 内存 / 行数上限、禁网禁写）
   → 失败带错误信息重写或换路径。
5. **图表与解读**：结果集 → 图表 figure（按问题形态选择图型）→ 大模型生成文字解读与关键数值，
   全程 **SSE 流式**推送到前端。
6. **多轮追问与澄清**：条件芯片展示当前生效条件，支持点选编辑后重算；追问只改变化的部分。
7. **评测与迭代**：120 题自动判分 → 分类正确率 / 结论命中率 / 延迟 / 归因 →
   bad case 逐题复盘 → 迭代提示词、Schema 与代码守卫。

## 六、技术点

- **前端技术**（以 `package.json` 实际安装版本为准）：Vite 6、React **18.3**、TypeScript 5.7、
  Ant Design **5.22**、Tailwind CSS **3.4**（关闭 `preflight` 与 AntD 共存）、plotly.js（自封装容器）、
  axios、zustand、`@microsoft/fetch-event-source`（SSE 需 POST + 鉴权头，原生 EventSource 不适用）
  > 说明：React 停在 **18.x** 而非 19 —— Ant Design 5 对 React 19 的兼容尚未完全收敛（见 PRD 10.3）。
- **后端技术**：Python 3.13（3.12+）、FastAPI、SQLAlchemy、Pydantic v2、SSE（sse-starlette）、JWT 鉴权
- **Agent 编排**：**LangGraph 状态图**（`app/agent/graph.py`：13 节点 + 条件边 —— 重写环 / 形态自检环 / 澄清环）
  + 提示词集中管理（`agent/prompts.py`）+ 双工具路由（query_sqlite / run_pandas）
  + slot 增量继承与澄清回路 + **会话级检查点**（`checkpoints` / `writes`）+ **澄清 HITL**（`interrupt()` / `resume` 断点续跑）
  > 说明：**LangGraph 1.2.14 已接入并成为默认编排**（`ORCHESTRATOR=langgraph`，`legacy` 可一行回退）；
  > 两条路径由 9 条等价性用例 + 120 题 selfcheck 逐题比对保证等价（见架构文档 ADR-021）。
- **安全与沙箱**：sqlglot 只读 SQL 白名单（含"两套拆分混加"检测）、
  pandas 代码 **AST 预检 + 子进程隔离**（超时强杀 / 内存上限 / 结果行数上限 / 禁网禁写）、审计留痕
  > 说明：`RestrictedPython` 已安装但**未接入执行链**，作为进程内第三道防线的预留候选。
- **数据存储**：SQLite **双库分离** —— `reports.db`（报表数据，应用侧只读）与
  `power_agent.db`（用户 / 会话 / 记录 / 评测，读写）
- **大模型服务**：任意 OpenAI 兼容厂商（**默认与实测为阿里云百炼**，换厂商只改 `.env`），
  按阶段分级使用轻量 / 主力模型，评测固定 `temperature = 0` 保证同题可复现

## 七、应用功能

1. **登录与注册**：
   - 用户名 + 密码注册（密码强度校验、bcrypt 哈希）、登录签发 24h Token
   - 连续失败锁定、账号停用拦截、审计留痕（注册 / 登录 / 失败 / 锁定 / 登出）

2. **对话工作台（核心页）**：
   - 自然语言提问 → 流式返回：条件 chips、执行的 SQL / 代码、结果表格、图表、文字解读
   - 条件芯片可点选编辑后重算；缺关键条件时返回**澄清卡**（点选后原地继续执行）
   - 会话列表（置顶 / 搜索 / 日期筛选）、消息历史游标分页、消息卡片可回看

3. **报表管理**：
   - CSV 上传两步向导（解析预览 → 确认入库）、动态建表与 Schema 自动生成
   - 报表列表与切换活跃报表、Schema 数据字典、数据质量与口径校验结果、数据预览

4. **评测中心**：
   - 发起评测批次（真实模型 `real` / 自检回放 `selfcheck`，后者置顶标注"不代表模型能力"）
   - 分类正确率（题型 / 难度 / 陷阱题）、结论命中率、延迟与归因、逐题明细与错题复盘
   - 报告导出（Markdown 下载 / PDF）

5. **个人中心**：
   - 账号信息、分析统计（会话 / 报表 / 记录数、近 7 天趋势）
   - 分析记录管理与详情（含逐阶段模型调用明细）、重跑
   - 编辑资料 / 修改密码 / 清空历史记录 / 删除账号
