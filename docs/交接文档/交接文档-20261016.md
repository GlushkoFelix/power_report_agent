4. **服务会被外部杀掉**（日志无崩溃痕迹）：计划任务常驻 + 长任务前 `_t2_ensure.cmd <端口> <任务名>` 自愈；
   批次 **≤30 题**（`P-030`）；长批次用计划任务跑，别依赖工具 shell。
5. **Windows 命令三条铁律**：`.cmd` 文件必须**纯 ASCII**（中文注释会让 cmd 按 GBK 解析破坏脚本）；
   命令里**别混用** `&` 与 `powershell -Command`；自写启动脚本必须有 `if __name__ == "__main__":` 守卫。
6. **口径纪律**：任何成绩引用必须带**四要素**（配置 / 端点 / 提示词版本 / 时段）；**抽样读数不可与 120 题全量互比**；
   **不要改判定口径**（一改历史 120 题成绩全部不可比）。
